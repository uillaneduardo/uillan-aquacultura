# Uillan Aquacultura

Mod de piscicultura e aquaponia para RimWorld, planejado para versões 1.5, 1.6 e 1.7.

**Estado:** estrutura inicial e documentação; mecânicas ainda não implementadas.

- `Aquacultura/`: pasta do mod para instalar em `RimWorld/Mods`.
- `Source/`: código-fonte C# e projetos de compilação por versão.
- `docs/`: especificação, arquitetura e plano de validação.

Consulte `docs/ESCOPO.md` e `docs/ARQUITETURA.md` antes de implementar funcionalidades.
